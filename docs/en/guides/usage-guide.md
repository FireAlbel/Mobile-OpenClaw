# Mobile-OpenClaw Usage Guide

## 📱 Device Management

### Connecting Devices
1. Connect Android devices to your computer using USB cables
2. Enable Developer Options and USB Debugging on each device
3. The system will automatically detect and display connected devices

![Device Management](../assets/images/设备管理.png)

### Device Information
Each device card displays:
- **Device Title**: Customizable device name
- **Device ID**: Unique identifier recognized by ADB
- **Port**: Device connection port
- **Model**: Device model information
- **Brand**: Device manufacturer
- **Remark**: Custom note information
- **Status**: Online/Offline/Unauthorized

### Device Operations
- **Connect**: Start screen mirroring control
- **Command**: Send ADB commands
- **Edit**: Modify device information

## 📝 Editing Device Information

### Changing Device Title
1. Click the "Edit" button on the device card
2. Enter a new device title in the popup dialog
3. Click confirm to save

### Adding Device Remarks
1. Click the "Edit" button on the device card
2. Add description information in the remark input box
3. Click confirm to save

### Device Grouping
1. Click the "Edit" button on the device card
2. Select an existing group or create a new one
3. Click confirm to save

## 👥 Group Management

### Creating Groups
1. Click the "New Group" button in the toolbar
2. Enter a group name
3. Click confirm to create

### Editing Groups
1. Click the "Edit" button next to the group name
2. Modify the group name
3. Click confirm to save

### Deleting Groups
1. Click the "Delete" button next to the group name
2. Enter the group name to confirm deletion
3. Click confirm to delete

## 🎮 Screen Mirroring Control

### Starting Screen Mirroring
1. Click the "Connect" button on the device card
2. Wait for the screen mirroring window to launch
3. Operate within the screen mirroring window

### Remote Control
- **Touch**: Click and swipe within the screen mirroring window
- **Input**: Use keyboard to input text
- **Keys**: Simulate device key operations

## ⚙️ Batch Operations

### Batch App Installation
1. Click the "Batch Operations" button in the toolbar
2. Select "Batch App Management"
3. Choose the app file to install
4. Select target devices
5. Click start installation

### Batch Group Control
1. Click the "Batch Operations" button in the toolbar
2. Select "Batch Group Control"
3. Choose devices to control
4. Execute batch operations

## 🔍 Search and Filtering

### Device Search
Enter keywords in the search box, and the system will automatically filter and display matching devices.

### Status Filtering
Click status tags to quickly filter devices with different statuses.

## 🛠️ Advanced Features

### Automation Scripts
- Create custom automation scripts
- Set scheduled tasks
- Execute scripts in batches

### Data Export
- Export device information
- Generate operation logs
- Create reports

## 💡 Usage Tips

1. **Device Naming Convention**: Use unified naming rules for better management
2. **Regular Maintenance**: Periodically check device connection status
3. **Grouping Strategy**: Group devices by purpose or project
4. **Configuration Backup**: Regularly backup device configuration information
