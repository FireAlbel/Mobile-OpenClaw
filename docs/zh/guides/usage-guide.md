# Mobile-OpenClaw 使用指南

## 📱 设备管理

### 连接设备
1. 使用 USB 数据线将 Android 设备连接到电脑
2. 在设备上启用开发者选项和 USB 调试
3. 系统将自动检测并显示设备

![设备管理](../assets/images/设备管理.png)

### 设备信息
每个设备卡片显示：
- **设备标题**：可自定义的设备名称
- **设备ID**：ADB识别的唯一标识符
- **端口**：设备连接端口
- **型号**：设备型号信息
- **品牌**：设备制造商
- **备注**：自定义备注信息
- **状态**：在线/离线/未授权

### 设备操作
- **连接**：启动投屏控制
- **指令**：发送ADB命令
- **编辑**：修改设备信息

## 📝 编辑设备信息

### 修改设备标题
1. 点击设备卡片上的"编辑"按钮
2. 在弹出的对话框中输入新的设备标题
3. 点击确认保存

### 添加设备备注
1. 点击设备卡片上的"编辑"按钮
2. 在备注输入框中添加描述信息
3. 点击确认保存

### 设备分组
1. 点击设备卡片上的"编辑"按钮
2. 选择已有的分组或创建新分组
3. 点击确认保存

## 👥 分组管理

### 创建分组
1. 点击工具栏上的"新建分组"按钮
2. 输入分组名称
3. 点击确认创建

### 编辑分组
1. 点击分组名称旁的"编辑"按钮
2. 修改分组名称
3. 点击确认保存

### 删除分组
1. 点击分组名称旁的"删除"按钮
2. 输入分组名称确认删除
3. 点击确认删除

## 🎮 投屏控制

### 启动投屏
1. 点击设备卡片上的"连接"按钮
2. 等待投屏窗口启动
3. 在投屏窗口中进行操作

### 远程控制
- **触控**：在投屏窗口中点击和滑动
- **输入**：使用键盘输入文本
- **按键**：模拟设备按键操作

## ⚙️ 批量操作

### 批量安装应用
1. 点击工具栏上的"批量操作"按钮
2. 选择"批量应用管理"
3. 选择要安装的应用文件
4. 选择目标设备
5. 点击开始安装

### 批量群控
1. 点击工具栏上的"批量操作"按钮
2. 选择"批量群控"
3. 选择要控制的设备
4. 执行批量操作

## 🔍 搜索和过滤

### 设备搜索
在搜索框中输入关键词，系统会自动过滤显示匹配的设备。

### 按状态过滤
点击状态标签可以快速过滤不同状态的设备。

## 🛠️ 高级功能

### 自动化脚本
- 创建自定义自动化脚本
- 设置定时任务
- 批量执行脚本

### 数据导出
- 导出设备信息
- 生成操作日志
- 创建报表

## 💡 使用技巧

1. **设备命名规范**：使用统一的命名规则便于管理
2. **定期维护**：定期检查设备连接状态
3. **分组策略**：按用途或项目对设备进行分组
4. **备份配置**：定期备份设备配置信息
